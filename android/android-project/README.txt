This folder should contain a copy of SDL's android-project template. To obtain:

1. Clone SDL's repo or download the android project template:
   git clone https://github.com/libsdl-org/SDL.git
2. Copy the contents of SDL/android-project into this folder.

After copying, add the native .so built by the scripts/android_build.ps1 into app/src/main/jniLibs/arm64-v8a/ and then open the folder in Android Studio.
